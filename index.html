장비 등급 기준표
등급은 서로 다른 두 가지를 봅니다. 혼동하지 마세요.
① 관리 우선순위 등급 = 얼마나 집중 관리해야 하는가 (고장 시 피해가 클수록 S)
② 설비 상태 등급 = 설비가 얼마나 새것·건전한가 (신품·양호일수록 S, 노후·고장多일수록 C)
→ 신품 설비라도 중요 공정이면 ①은 S가 될 수 있습니다. 두 등급은 독립입니다.
① 관리 우선순위 등급 — 얼마나 집중 관리할지
자동차부품 업계(IATF 16949 · TPM) 설비 중요도 평가 기준. 안전·환경(S) / 품질(Q) / 생산·가동(P) / 납기(D) / 원가(C) 항목을 평가해 등급을 결정합니다.
각 항목 중 가장 높은 등급을 최종 등급으로 채택합니다(최고치 우선).
등급 명칭 판정 기준 (자동차부품 · IATF 16949 / TPM)
S 최우선 관리
· 안전/환경(S) : 고장 시 인적 재해·중대 환경사고 우려, 안전장치 직결 설비
· 품질(Q) : 고객 중요특성(CC/SC) 가공·검출 설비, 오류 시 유출·리콜 위험, 양산 승인(PPAP) 연계
· 생산(P) : 고장 시 라인·셀 전체 즉시 정지 + 완충재고(버퍼) 없음 + 예비품·예비유닛 미보유로 당일 복구 불가, Bottleneck 공정 (※ 단독 설비라도 세 조건이 겹칠 때만 S)
· 납기(D) : 고객 직납·JIT 라인, 정지 시 고객 라인 정지(챠지) 가능
· 원가(C) : 연간 수리비 500만원 이상 또는 고장 빈도 월 1회 이상
· 법정 검교정 대상 계측·시험 설비, 단종/단종예정, 월 가동 상위, 노후 심화 설비 포함
→ 예방정비(PM) 최우선, 점검주기 최단, 예비품 상시 확보, 단종 전환관리
A 중요 관리
· 안전/환경(S) : 국부적 안전·환경 영향, 보호구·방호로 통제 가능
· 품질(Q) : 일반특성 가공, 불량 시 공정 내 검출 가능(후공정 유출 낮음)
· 생산(P) : 고장 시 해당 스테이션·공정만 정지, 또는 단독 설비라도 완충재고로 대응 / 예비품·예비유닛으로 당일 복구 / 병렬 셀로 물량 재배분 가능
· 납기(D) : 정지 시 재고로 단기 대응 가능하나 장기화 시 납기 차질
· 원가(C) : 연간 수리비 100~500만원 또는 고장 빈도 분기 1회 이상
→ 정기점검 철저, 소모품 선제 교체, 상태기반보전(CBM) 적용
B 일반 관리
· 안전/환경(S) : 안전·환경 영향 미미
· 품질(Q) : 품질 영향 경미, 외관·속도 저하 수준
· 생산(P) : 고장 시 속도 감소·부분 지연, 대체 설비 보유 / 즉시 전환 가능
· 납기(D) : 납기 영향 거의 없음
· 원가(C) : 연간 수리비 100만원 미만 또는 고장 빈도 반기 1회 이하
→ 계획 정비(TBM), 표준 점검주기 적용
C 저우선 관리
· 안전/환경(S) : 영향 없음
· 품질(Q) : 품질 무관
· 생산(P) : 고장 시 생산에 영향 없음, 보조 설비 / 유틸리티 장비
· 납기(D) : 영향 없음
· 원가(C) : 연간 수리비 30만원 미만 또는 고장 빈도 연 1회 이하
→ 사후 정비(BM) 위주, 점검주기 완화
복합 판정 원칙 (자동차부품)
S·Q·P·D·C 5개 항목을 각각 평가한 뒤 가장 높은 등급을 최종 등급으로 부여합니다.
예) 생산 영향도가 B라도 고객 중요특성(CC/SC) 가공 설비이거나 법정 검교정 대상 → S등급
예) 단종/단종 예정, 월 가동량 상위, 노후화 심화 설비 → S등급으로 상향, 분기별 정기 검토 권장
조립 등 단독 설비가 많은 공정 : '단독'이라는 이유만으로 전부 S로 두지 않습니다. ① 라인·셀이 즉시 전체 정지되는가 ② 완충재고(버퍼)로 버틸 수 있는가 ③ 예비품·예비유닛으로 당일 복구되는가 를 함께 보고, ①즉시 전체정지 + ②버퍼 없음 + ③당일 복구 불가가 겹칠 때만 S, 그 외 단독 설비는 A로 관리합니다. (예비유닛·예비품 확보로 등급을 낮출 수 있음)
※ 등급 재평가 주기 : 연 1회 정기 + 설비 신규 도입 / 공정 변경 / 고객 요구 변경 시 수시
② 설비 상태 등급 — 설비가 얼마나 새것·건전한지
설비 자체의 신품도·건전성을 나타냅니다. 경과년수 × 고장 빈도 × 노후·단종 상태로 판정하며, 신규 설비일수록 S, 노후·고장이 잦을수록 C입니다.
경과년수와 고장 빈도 중 더 낮은(나쁜) 등급을 최종 상태 등급으로 채택합니다.
등급 명칭 판정 기준 (경과년수 · 고장 빈도 · 노후 상태)
S 양호 / 신품
· 도입 3년 미만 (신규 설비 · 최신 사양)
· 고장 거의 없음 (연 0~1회, 경미)
· 정밀도·정도(精度) 규격 내, 외관·누유 이상 없음
· 예비품·소모품 정상 공급, 단종 부품 없음
→ 초기 유동관리(길들이기) 후 표준 예방정비 유지
A 정상
· 도입 3~7년
· 고장 빈도 연 1~2회
· 주요 부품 교체 이력 적음, 성능 저하 미미
· 단종 부품 일부 존재하나 대체품 확보 가능
→ 예방정비 + 소모품 주기 교체, 정도 정기 점검
B 경년 / 주의
· 도입 7~12년 (노후 진행 단계)
· 고장 빈도 분기 1회 내외
· 정밀도 저하·간헐 트러블, 오버홀(대수리) 시점 도래
· 핵심 부품 단종 조짐, 예비품 선제 확보 필요
→ 오버홀 계획 수립, 단종 부품 재고 확보, 갱신 검토 착수
C 노후 / 교체 검토
· 도입 12년 이상 (내용연수 초과)
· 고장 빈도 월 1회 이상, 수리비 급증
· 정밀도·안전 기능 저하, 잦은 임시 조치로 가동
· 핵심 부품 단종 / 제작사 지원 종료
→ 대수선 또는 설비 갱신(대체 투자) 품의, 단종 전환관리
상태 등급 판정 원칙
경과년수 등급과 고장 빈도 등급 중 더 나쁜 쪽을 최종 상태 등급으로 부여합니다.
예) 도입 4년(경과년수 A)이라도 월 1회 이상 고장 또는 핵심 부품 단종 → C
예) 도입 10년이라도 고장 이력 거의 없고 정밀도 규격 내면 → A 유지 가능
※ 경과년수 기준은 사내 표준 내용연수에 맞춰 조정하세요 (정밀가공·전자설비는 더 짧게).
